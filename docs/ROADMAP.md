# Roadmap

1. **Simple primitives** (done, printed on both printers). Cube, cylinder, cone and an orientation L,
   sliced and written as `.ctb` and `.m5sp`. Test print on both printers.
2. **Import simple geometry** (built, waiting for your try-out). Load STL,
   3D view, move / rotate / scale, layer preview, editable print settings.
3. **Calibration model.** Raft and basic automatic supports; print the Cones
   of Calibration and compare with the Lychee/Chitubox-sliced copy.
4. **Complex geometry.** Island detection, better automatic supports, manual
   support editing, mesh repair, faster slicing for big meshes.
5. **Split for assembly.** Cut a model with a plane, add alignment pins or
   keys, lay the parts out on the plate.
6. **Future plan.** Rank the remaining features (hollowing, anti-aliasing,
   arrange, ...) into a roadmap.
